# 🚀 SkillScope

SkillScope is a **React-based job market intelligence tool** that helps you understand the demand, salary trends, and required skills for any technology using real-time job data.

---

## 🔍 What It Does

Enter a skill (e.g., React, Python, Java) and SkillScope will:

- 📊 Show total job demand in India
- 💰 Estimate average salary (based on recent listings)
- 🧠 Extract trending related skills
- 📈 Classify job roles (Frontend, Backend, Full Stack)
- 💼 Display real job listings
